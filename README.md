# MyTetris-Waveshare

MyTetris Python program modified for the RaspberryPi Zero 2W and Waveshare 1.5 inch display (240 x 280). Pygame is replaced by the PIL graphics library for Waveshare display compatibility. Waveshare display is integrated with the Pi Zero 2W over SPI interface.

## Parts Used
(1) Raspberry Pi Zero 2W<br>
(10) switches - start, exit (future for multi-game expansion),  up/down/left/right, a/b/x/y<br>
(1) passive buzzer
